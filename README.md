# SafeAlert - App de seguridad y alerta de emergencia

Aplicación .NET MAUI basada en el proyecto final y en los diseños proporcionados.

## Pantallas
- Login
- Inicio con botón SOS
- Contactos de emergencia
- Envío de alerta
- Historial de alertas
- Perfil del usuario

## Ejecución
1. Abrir `SafeAlert.slnx` en Visual Studio.
2. Seleccionar **Windows Machine**.
3. Ejecutar con **F5**.
